# Scumble Studio 0.1.62

Modo sencillo por defecto con barra superior, herramientas a la izquierda, acciones y capas. Modo avanzado recupera la interfaz original. La preferencia se conserva localmente. Los controles avanzados siguen en inglés.

Quitar fondo usa BiRefNet Lite o BiRefNet instalado en Configuración > Helpers. Si se selecciona la imagen base, crea una copia editable con máscara; la base original permanece visible debajo. Usa PNG transparente para exportar solo la capa recortada. Los ajustes crean capas de filtro sobre el contenido inferior. Recortar/ampliar ajusta el marco; para expansión generativa, usar modo avanzado y configurar un modelo de generación.

Pruebas manuales pendientes en Windows: abrir, nuevo lienzo, texto, filtros, recorte PNG, cambio de modo, exportación, restaurar pestañas, instalación y actualización.
